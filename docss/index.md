## Quick Start

```bash
# Clone and configure
cp .env.example .env
# Fill in API keys: DEEPSEEK_API_KEY, DEEPGRAM_API_KEY, GROQ_API_KEY, POSTGRES_*

# Build and run all 4 containers
docker compose up --build

# Frontend: http://localhost (port 80)
# Interview API: http://localhost/api  (proxied from port 8000)
# Copilot API:   http://localhost/api  (proxied from port 8001)
```

## System at a Glance

```
Browser (React 19 + Vite)
    ↕ WebSocket (Raw PCM audio, 16kHz)
    ↕ REST (JSON)
        ↓
    Nginx (Reverse Proxy, port 80)
        ↓                    ↓
Interview Service       Copilot Service
(FastAPI, port 8000)    (FastAPI, port 8001)
    ↕ Pipecat Pipeline      ↕ 3× parallel LLM tasks
        ↓                       ↓
  Deepgram STT/TTS         DeepSeek LLM
  DeepSeek LLM             Groq LLM
  Silero VAD               Deepgram STT
        ↓                       ↓
    PostgreSQL 15 (shared)
    File System (./interviews/)
```
